# 工程师打工人生存模拟器（2D/2.5D 版本）

这是一个受《饥荒》《缺氧》启发的讽刺生存小游戏：

- 你扮演工程师，在办公室地图中移动并与设施交互。
- 通过 **工位产出、吃饭、休息、健身、被迫冲刺** 管理资源。
- 系统目标不是“无限加班”，而是找到可持续节奏并达成平衡结局。

## 核心机制

- 实时移动：WASD / 方向键
- 设施交互：靠近建筑后按 `E`
- 时间推进：每次交互推进时段；世界会持续资源衰减
- 多资源管理：精力、健康、心态、倦怠、饥饿、进度、薪资
- 多结局：透支、崩溃、燃尽式胜利、平衡结局

## 运行

直接打开 `index.html`，或使用静态服务器：

```bash
python3 -m http.server 8000
```
